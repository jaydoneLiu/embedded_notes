## 使用说明

1. 用 **Obsidian** 打开本文件夹：`嵌入式软件学习库`
2. 从各模块的 `_MOC`（内容地图）开始扩展
3. 新笔记可复制 `99-模板与资源` 下的模板
4. 需要发布成网站时，可用 Obsidian Publish / Quartz / VitePress 等，届时再配置
